# Project Rules for Ten Seconds

## Android APK Naming Rule
- Whenever generating an Android build, ALWAYS name the output file using progressive version numbers: `TenSeconds_Beta_X.apk` (e.g., `TenSeconds_Beta_11.apk`, `TenSeconds_Beta_12.apk`).
- Never name APKs generically like `app-debug.apk` or `latest.apk`.
